# Foodwagon Clone

A React recreation of the Foodwagon food delivery experience.

## Tech stack

- React 19 with Vite
- React Router DOM
- Tailwind CSS with PostCSS and Autoprefixer
- ESLint

## Getting started

```bash
npm install
npm run dev
```
